# Isomorphic Invariant Orders Without Hermite Equivalence

Deep Bhattacharjee

Bhargava, Evertse, Győry, Remete and Swaminathan asked whether, in every degree n ≥ 4, there are integral polynomials with isomorphic invariant orders that are not Hermite equivalent; they answered the question for n = 4. This paper answers it for every even n and for every n with n − 2 divisible by 3, 5 or 7, with explicit pairs. In degree six one polynomial of the pair can be chosen monic.

- `paper/`: LaTeX source (amsart, pdflatex), figures and PDF
- `code/verify_resultants.py`: recomputes every resultant, discriminant and class-group check in the paper (needs `cypari2`)
- `figures/figs.py`: draws the two figures
